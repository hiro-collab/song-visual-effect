# Effect Direction: トラフィック・ジャム

## Intent

この曲の映像は、事故そのものよりも「事故をきっかけに視線と責任が一点へ集まる状態」を中心に置く。全体は暗く、観客や街の輪郭は見えにくい。その中で、赤信号、白いフラッシュ、細い視線、警告色だけが鋭く浮かぶ。

既存MVの再現ではなく、曲のモチーフをインタラクティブ映像向けに抽出する。キーワードは、渋滞、衝突、視線、バッシング、停止、再発進、袋小路。

## Major Rules

### 1. Dark World, Sharp Gaze

画面の基本値は暗くする。背景情報は少なく、輪郭と信号色で場所を伝える。

視線はこの曲の主役に近い。ライト、カメラ、目線、通知、指差し、矢印をすべて「注目の線」として扱う。ユーザー入力は、視点を動かすというより、注目の偏りを少し変える操作にする。

### 2. Impact Is Selective

130BPMの4拍は常にあるが、全拍を大きく揺らすと単調になる。通常ビートは信号や街灯の小さな点滅に留め、キック、スタブ、セクション頭、サビ突入などの強いブローだけを衝突として扱う。

大きい反応:

- 一瞬のカメラ押し込み。
- ヘッドライトの白飛び。
- 道路標識や矢印のスナップ回転。
- 中央から薄い衝撃波。

小さい反応:

- 赤信号の脈動。
- 路面ラインの短い発光。
- 遠景のフラッシュ。

### 3. Bashing Is Visual Pressure

バッシングは文字の罵倒で説明しない。映像としては、中央の影へ向かう指差し、矢印、カメラフラッシュ、通知ブロック、赤い視線で表現する。

重要なのは「誰かが正しいことを言っている」ではなく、「注目と責任転嫁が群れとして一人へ集中している」こと。責める側も渋滞の一部として扱い、矢印や視線が増えるほど画面全体も詰まるようにする。

### 4. Interlude Is A Different Room

間奏は他のシーンと同じ道路空間にしない。時間が止まった証拠品の部屋として、信号機、車輪、標識、フラッシュ、手のシルエットなどが無重力で浮く。

動きは少なく、遅れて反応する。ユーザー入力から少し遅れてオブジェクトが傾き、曲が戻る直前に一斉に本来の重力へ引き戻される。

## Scene Model

### Base Scene A: Jam / Collision

暗い交差点。低ポリ車、信号機、横断歩道、路面ライン、標識、カメラフラッシュを置く。

車は進んでいるようで進まない。一定のビートで少し動き、強いブローで衝突フレームに切り替わる。マウス位置やタッチ位置は、周囲の視線とフラッシュの集まり方に影響する。

### Base Scene B: Cul-de-sac / End World

道路が折れ曲がり、最後は袋小路へ収束する。サビ後半と終盤で使う。

信号と矢印が反復し、二人の影や中央の対象が出口を失う。終盤の連続サビでは、渋滞、バッシング、警告灯が全部重なり、逃げ場が消える。

### Override Scene: Bashing Barrage

中央に対象の影を置き、周囲から視線、矢印、通知、フラッシュが刺さる。通常シーンに重ねてもよいし、一時的に全面切り替えしてもよい。

音への反応はボーカルの細かい語尾と強いブローを優先する。将来の手動マーカーで、歌詞上の責任転嫁や煽りが強い箇所を補強する。

### Override Scene: Interlude Freeze

Songleのコード推定上、2:26付近から短い和音変化が見える。ここは暫定的に 2:26.3-2:39.3 を候補範囲にする。

通常の道路ループを止め、標本箱のような空間に切り替える。強いリズム反応は抑え、薄い回転、遅延、点滅だけで不穏さを作る。

## Data Policy

- 音源ファイルは同梱しない。
- 音源波形は解析しない。
- 歌詞全文は同梱しない。
- Songle由来データは拍、サビ、構造の目安として使う。
- キックやブロー、バッシング語尾などの重要点は、後で手動マーカーとして追加する。

## Next Implementation Notes

最初の実装では、3Dを作り込みすぎない。

必要なモデルは、低ポリ車、信号機、標識、コーン、街灯、矢印、シルエット程度で足りる。3Dモデルが重い場合は、2D板ポリゴンやCSS/Canvas/SVGでもよい。重要なのは、暗闇の中で視線と警告色が鋭く集まること。
