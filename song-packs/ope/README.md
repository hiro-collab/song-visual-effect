# オペ

This song pack is for the visual-effect work on "オペ" by 蜂屋ななし feat. v4 flower. It intentionally starts from the neutral authoring flow and does not copy an existing song pack structure.

- Adapter: `song:ope` neutral start

## Current Design Direction

The current design treats the song as an operating room being invaded by public records, news-like judgment, and outside evaluation pressure. It is not a live-stage visual. The core objects are a clinical table, offset procedure lights, monitors, triage boards, diagnosis panels, verdict cards, and a single pulse trying to stay readable. The visual should stay symbolic and avoid graphic self-harm or gore.

See `design/research.md`, `design/visual-brief.md`, `design/timeline-map.md`, `analysis/structure-map.json`, and `design/effect.json` for the current research, time map, and screen composition plan.
