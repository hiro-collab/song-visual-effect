新規作業者の入口

会話履歴に頼らず、リポジトリ内の地図から作業を始めるための最短導線です。

  1. 最初に読む AGENTS.md → docs/thread-start.md → docs/handoff.md
  2. 同期を見る git status と npm run sync:check。ready通知は取り込み候補として判断します。
  3. 新曲作成 既存song-packsやfixture effectsを読まず、song-authoring系docsから始めます。
