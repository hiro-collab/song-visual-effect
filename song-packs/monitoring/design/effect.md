# Monitoring Effect

`DECO*27 - モニタリング` 用の曲固有エフェクト。主役はサイバー監視室ではなく、暗いドア手前から覗き穴越しに見える明るい居住空間。監視している主体は、部屋の中のメモや柔らかい光を通して、人間の感情的・共感的な魅力をアピールする。

- Beat: 室内灯、カーテン、手書き波形、金属リングの反射を揺らす。
- Chorus: MVを参考にした大きな眼、ハート、リボン状のポップな侵食を増やし、可愛さの奥にある近づきすぎる圧を強める。
- Pointer: 覗き穴越しの焦点として扱う。
- User glow: 近づき度。ドアスコープの圧、眼の気配、共感メモの説得力を強める。ただし部屋の明るさと生活感を優先する。

歌詞参照メモ:

- 本文は表示しない。相手の弱さを知り、支えたい気持ちと、境界を越えて覗き込む危うさの二重性を、監視している主体の訴えとして演出へ反映する。主体は「自分は共感できる、優しく支えられる」と見せることで、欲望を正当化しようとしている。不気味さは背景の含みに留め、画面上では人間味のアピールと生活空間の明るさを優先する。
- MV情報にあるドアスコープの導入、大きな眼、可愛さと危うさ、視界を侵食するポップな演出を参照する。

視覚独立性メモ:

- 中央発光、放射線、光ネットワーク、粒子主体の演出を避ける。
- 曲固有の覗き穴、居住空間、手書きメモ、ポップな侵食記号を優先し、監視UIは主役にしない。
- 音源ファイルは同梱しない。Songle由来のbeat/chorus JSONだけを使う。
